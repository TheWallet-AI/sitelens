# Contributing

Use English for code, comments, documentation, issues, and pull requests. Preserve original website evidence where translation would alter meaning.

Create a feature branch, install dependencies with `npm ci`, and add meaningful regression tests for behavior changes. Run tests, type checking, lint, and the production build before opening a pull request. For UI changes, run Playwright on desktop and mobile and include screenshots.

Keep the core usable without AI credentials or an Infoholder account. Recommendations must remain optional and independent of findings. Never claim measured AI visibility from heuristic readiness checks. Do not commit credentials, private reports, or fetched user data.
